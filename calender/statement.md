# Problem Statement
People often need a fast, distraction-free way to check dates and jot down quick notes directly from their command line. Opening heavy web applications or graphical desktop calendars can be slow and interrupt a developer's workflow. 

# Scope of the Project
The project provides a minimalist, text-based terminal interface. Users can generate monthly calendars and perform Create and Read operations for events. The scope is limited to local offline usage, with data securely saved to a plain text file on the user's machine.

# Target Users
* Software developers and terminal-power users.
* Students needing a simple, fast assignment tracker.
* Anyone looking for a minimalist, distraction-free planner.

# High-Level Features
* Text-based calendar generation.
* Interactive Command Line Interface (CLI) menu.
* File-based data persistence.
* Zero-dependency architecture (runs on pure Python).
